# MausamSetu — 26 September 2026 release

## Running deployment

The Docker-native research deployment runs on the authorized Mac at `http://127.0.0.1:4173`. The `/sih` page shows measured test evidence, the real-data benchmark and current operational status.

Services comprise the standalone Next.js frontend, FastAPI backend, Postgres, replay/observation worker, hourly ingestion/maintenance worker and daily database-backup worker. Public products, native provider cache, scientific artifacts and backups use separate persistent volumes.

This is not public cloud hosting, institutional authorization or an approved public-warning service. NCUM/latest-cycle NEPS access and an institutional identity provider remain unconfigured.

## Implemented changes

Real GFS/AIFS ingestion preserves source metadata and checksums, aligns precipitation windows, flags unavailable cells and publishes immutable products. The connected browser checks for new publications without resetting the selected location or disguising refresh failures.

The adaptive engine trains context-dependent CRPS weights and publishes per-grid source contributions. Candidate checksums, review records, active-version inference and rollback are implemented. Synthetic testing cannot approve a real operational forecast.

The observation pipeline validates exact grids, units, valid intervals, release times, revisions and reference identities. A worker processes released normalized observation batches once, with quarantine receipts for invalid input.

Signed-token tests exercise viewer, reviewer and approver boundaries. Scientific downloads remain protected; the public projection has a restricted source allowlist. Production configuration rejects anonymous institutional access.

## Scientific evidence

A real temperature experiment uses WeatherBench IFS-HRES, Pangu and ERA5 over an India-region bounding box on a common 1.5-degree grid. The reference is reanalysis, not independent station observations. The 180 selected initialization dates span 2018–2022, with 24-, 72- and 168-hour leads.

Calibration uses 2018; gate training uses 2019–2020; model selection uses 2021; the held-out test uses 2022. There are 104,328 training grid/lead cases and 52,164 held-out cases from 36 initialization dates.

| Distribution | Test RMSE, degrees C | Test CRPS, degrees C |
| --- | ---: | ---: |
| Equal mixture | 1.2667 | 0.61645 |
| Static mixture | 1.1441 | 0.55879 |
| Adaptive mixture | 1.1436 | 0.54936 |

Adaptive-minus-static CRPS has a 95% interval of approximately -0.01478 to -0.00356 using 12 monthly bootstrap blocks. The full report also shows individual sources, biases and by-lead results. Adaptive bias is not uniformly better.

The temperature result does not establish wind, extreme-event or station-based operational skill. The bounding box includes neighboring land and ocean cells. ERA5-initialized Pangu is a retrospective experiment, not a real-time replay. These weights are not transferred to the live GFS/AIFS roster. The candidate remains ineligible for production promotion.

A second real-data experiment evaluates IFS-HRES + GraphCast 24-hour rainfall against ERA5 on the same India-region style bounding box for 36 selected 2020 initialization dates and 24-, 72- and 168-hour leads. Calibration uses January–February, gate training March–June, selection July–August and the held-out test September–December. Adaptive CRPS is 1.19493 mm versus 1.20805 mm for the static mixture; the 95% initialization-block interval for adaptive minus static CRPS is about -0.02194 to -0.00484. This is bounded retrospective evidence, not operational acceptance.

The rainfall report includes fixed 20, 64.5 and 115.6 mm/24h event diagnostics, algorithmically selected held-out replay cases and explicit failure cases. Only one held-out case exceeds 115.6 mm/24h, so the experiment cannot support a severe-tail skill claim. ERA5 is reanalysis rather than independent Indian gauge truth, and GraphCast is retrospective rather than a live as-of source.

## Executed checks

63 backend tests pass on the host, covering distributions, learned inference, source masking, immutable publication, observation verification, signed-token roles, context-feature anti-hindsight checks and India-source readiness contracts. The current browser suite contains 15 tests and passes against packaged products; connected-archive mode is rerun after the Docker API/public projection is started. Type checking, production builds, public-data checksum/shape checks, 280 synthetic forecast combinations and 2,880 synthetic verification records pass.

A real API outage returned an explicit frontend 503 without substitute data; recovery restored normal publication access. Isolated Postgres and scientific-artifact restores succeeded. Linux GRIB decoding of cached GFS/AIFS data succeeded. The final production-dependency npm audit reported zero known vulnerabilities; this is not a security certification.

## Operational notes

The first macOS launch-agent attempt stalled before service availability. Those agents were disabled and archived; Docker is the active scheduler and deployment. No operating-system security setting was bypassed.

During Docker builds, the 5 GB disk-space guard paused ingestion as intended. Approximately 6 GB of disposable build cache created during this work was reclaimed. Source code, research files, running images and database volumes were preserved. The service then returned to healthy status with completed backups.

The runtime reports are under `/sih` and `/api/operations`. Backups and audit evidence are local. Services run while Docker and the Mac are available; laptop sleep or shutdown is not an always-on service guarantee.

## Remaining external acceptance gates

Working latest-cycle NCUM/NEPS access and applicable permissions are still required. A private delayed NEPS sample does not establish a production feed, and no authorized NCUM numerical file is currently staged.

A real 2020 IMD 0.25° gridded-rainfall file is staged privately, while the tested IMD operational endpoint still requires approved access/IP whitelisting. MOSDAC current rainfall catalogue discovery works but numerical download credentials are not configured. Exact observation-window collocation, source-specific calibration for the live roster, multi-season rainfall/wind/extreme evaluation, named-regime validation and prospective shadow testing are still required. Software cannot manufacture those data or approvals.

The institution must configure its identity provider, HTTPS ingress, distribution policies, reviewer authority and operational ownership. Off-site backups and external paging are not configured. No public cloud resource was purchased or deployed during this work.

The defensible release description is **a running, hardened research deployment with a tested forecast-fusion engine and SIH demonstration evidence**—not a fully approved NCMRWF operational forecast service.
